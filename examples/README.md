# Examples

These scripts are the public-facing v0.2.0 quickstart demos. They are deterministic,
fast, and designed to run without external data sources.

## Public v0.2.0 scripts

- `bs_analytic_greeks.py`
- `mc_pricing_and_stderr.py`
- `pde_theta_scheme.py`
- `pde_greeks_demo.py` (also `--case startup`)
- `tree_convergence.py`
- `american_put_cross_method.py`
- `american_put_binomial_dp.py`
- `digital_option_cross_method.py` (also `--case pde`)
- `mc_variance_reduction.py` (also `--case digital`)
- `asian_option_control_variate.py` (also `--case fixings`)
- `quadrature_demo.py`
- `laplace_inversion_demo.py`
- `copula_gaussian_demo.py`
