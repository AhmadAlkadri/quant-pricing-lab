# Numerics

Numerical utilities live in:

- `qpl.numerics.linear_systems`
- `qpl.numerics.quadrature`

Main building blocks:

- iterative linear solvers: Jacobi, Gauss-Seidel, SOR
- quadrature rules: composite trapezoid, composite Simpson, Gauss-Legendre

These utilities are designed for educational workflows and deterministic testing.

See `examples/quadrature_demo.py` and `notebooks/02_numerical_toolkit.ipynb`.
