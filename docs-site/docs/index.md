# qpl Documentation

`qpl` (Quant Pricing Lab) is a pre-1.0 numerical-methods lab for option pricing under
Black–Scholes and Heston, built by Textbook-Driven Development: each result is
re-derived, turned into an executable case, cross-checked by an independent method and
backed by measured convergence or statistical evidence. It is not a production trading
framework.

These pages describe the v0.3.0 source milestone. The curriculum and the derivation notes
are rendered from the repository's `docs/` folder, which is their single source.
